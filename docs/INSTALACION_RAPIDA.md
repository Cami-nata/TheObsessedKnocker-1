## 📦 PASOS DE INSTALACIÓN

### 1. Preparar Archivos

```powershell
# Opción A: Usar archivos traducidos (reemplazar originales)
copy "spelen_ES.mcfunction" "spelen.mcfunction"
# fakkel.mcfunction ya está modificado

# Opción B: Mantener ambas versiones
# Los archivos _ES están listos como referencia
```

### 2. Comprimir Addon

1. Selecciona las carpetas:
   - `KNOCKERbeh2`
   - `KNOCKERres2`

2. Click derecho → **Enviar a → Carpeta comprimida**

3. Renombra el ZIP a: `TheObsessedKnocker_ES.mcaddon`

### 3. Instalar en Minecraft

**Método 1 (Más fácil)**:
- Doble click en `TheObsessedKnocker_ES.mcaddon`
- Minecraft se abrirá automáticamente
- Los packs se instalarán

**Método 2 (Manual)**:
- Copiar `KNOCKERbeh2` a:
  ```
  %localappdata%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\behavior_packs\
  ```
- Copiar `KNOCKERres2` a:
  ```
  %localappdata%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\resource_packs\
  ```

### 4. Activar en Mundo Nuevo

1. Crear mundo nuevo
2. Configuración del mundo
3. **Packs de Recursos** → Agregar → "The Obsessed Knocker (Resource)"
4. **Packs de Comportamiento** → Agregar → "The Obsessed Knocker (Behavior)"
5. **Experimentos** → ✅ Activar "Beta APIs"
6. Crear mundo

---

## 🎯 CÓMO JUGAR

### Inicio
1. Al entrar al mundo recibirás **"The Whisper"** (El Susurro)
2. Usa el item para abrir el menú
3. El Knocker aparecerá naturalmente después de 2 días en el juego

### Interactuar
- Usa "The Whisper" para hablar con él
- Cada conversación aumenta tu vínculo
- 4 niveles: Desconocido → Vigilado → Familiar → Obsesionado

### Comandos
```
.bond         Ver tu nivel de vínculo
.bond 250     Establecer vínculo en 250
.bond +50     Aumentar 50 puntos
```

## 🐛 PROBLEMAS COMUNES

### El Knocker no aparece
**Solución**: Espera 2 días en el juego, o usa el menú → "Find me"

### Los diálogos están en inglés
**Esto es normal**: Solo ~8% está traducido (ver `README_TRADUCCION_ES.md`)

### Error al cargar el mundo
**Soluciones**:
- Verifica que Beta APIs esté activado
- Confirma versión 1.21.50+
- Reinstala los packs

### "The Whisper" desapareció
**Solución**: El juego lo re-dará automáticamente cada 10 segundos
